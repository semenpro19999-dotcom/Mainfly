# 🪰 Mainfly — Drosophila Connectome Agent for Minecraft (Fabric 1.20.1)

Бот подключается к Minecraft как полноценный игрок и управляется биомиметической спайковой моделью мозга дрозофилы (*Drosophila melanogaster*):
- **Фасеточное зрение (Омматидии):** круговой 360° анализ освещенности и оптического потока.
- **Центральный комплекс (Central Complex):** кольцевой аттрактор (E-PG нейроны компаса) и фототаксис (тяга к источникам света).
- **Giant Fiber System:** рефлекторное бегство при резком приближении мобов или затенении.
- **Нисходящие моторные нейроны (DN):** генерация саккад (поворотов), поступательного движения и лунной походки (MDN).

Потребляет **менее 150 МБ ОЗУ** и около 2-4% процессора!

---

## Что нужно установить на твой ПК (Windows):

1. **Node.js (LTS)**:
   - Скачай с официального сайта: [nodejs.org](https://nodejs.org/) (кнопка LTS).
   - Установи (просто нажимая «Далее»).

2. **Minecraft Fabric 1.20.1**:
   - Твой обычный лаунчер (TLauncher, Prism Launcher, Modrinth или официальный).
   - Для максимальной производительности на слабом ПК рекомендуются моды в папку `.minecraft/mods`:
     - `fabric-api`
     - `sodium` (дает огромный прирост FPS на RX 480)
     - `ferritecore` (сокращает потребление ОЗУ Майнкрафтом почти в 2 раза)

---

## Как запустить бота:

### 1. Скачай этот репозиторий:
Склонируй через Git или скачай ZIP-архивом и распакуй в любую папку.

### 2. Установи зависимости (один раз в терминале в папке проекта):
```bash
npm install
```

### 3. Настрой подключение:
Создай файл `.env` (скопируй из `.env.example`):
```env
MC_HOST=localhost
MC_PORT=25565
MC_USERNAME=Drosophila_Fly
```
## Общение и команды на русском языке:

Муха слушает игровой чат и реагирует на твои слова:
- **«молодец» / «молодца» / «умница» / «хорош»** — радостный прыжок, октопаминовая похвала, закрепление опыта.
- **«ломай» / «копай» / «разбей»** — муха начинает ломать блок перед собой лапками или киркой.
- **«поставь» / «строй»** — берет блок из инвентаря (земля, камень, доски) и устанавливает под собой.
- **«бей» / «атакуй» / «фас»** — наносит удар лапками по ближайшему мобу или игроку.
- **«что у тебя» / «инвентарь»** — перечисляет в чат все вещи, которые держит в лапках.
- **«ко мне» / «иди сюда»** — поворачивается к игроку и делает рывок навстречу.
- **«как дела» / «как ты»** — рассказывает про свое здоровье и сколько раз ей было бо-бо или её хвалили.


### 4. Запусти бота:
```bash
npm start
```

Муха сразу появится в твоём мире как игрок!
